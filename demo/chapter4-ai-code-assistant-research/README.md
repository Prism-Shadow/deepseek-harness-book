# 第 4 章调研案例配套文件

本目录保存第 4 章“让 dsh 完成一次调研”案例的完整输出，包括研究说明、研究计划、三份并行研究材料、核验记录和最终报告。

案例围绕一个具体问题展开：一家约 200 人、主要在中国开展业务的软件公司，是否应该在未来 12 个月内为研发团队引入 AI 代码助手？

按照下面的顺序阅读，可以看到这项调研怎样从问题定义走到最终报告：

1. `AI代码助手调研/01-研究说明.md`
2. `AI代码助手调研/02-研究计划.md`
3. `AI代码助手调研/研究材料/` 中的三份并行调研结果
4. `AI代码助手调研/03-核验记录.md`
5. `AI代码助手调研/04-决策报告.md`

三份研究材料保留了子代理最初整理的结论和来源，其中也能看到后来发现的口径冲突和事实错误。接着阅读 `03-核验记录.md`，可以看到这些问题怎样被核对；`04-决策报告.md` 给出了修正后的最终建议。

这次调研和核验完成于 2026 年 8 月。AI 代码助手的产品名称、价格、功能和合规口径变化较快，实际采购或合规决策前需要重新核对官方资料。
