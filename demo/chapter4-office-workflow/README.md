# 第 4 章办公案例配套文件

本目录保存“产品发布会费用复盘”案例使用的固定输入文件和提示词。按照正文操作前，请复制整个目录，再将副本作为 DSH 工作区，避免修改仓库中的原始材料。各小节的提示词保存在对应目录的 `prompts.md` 中。

```text
chapter4-office-workflow/
├── 4-1-excel/
│   └── source/
│       └── 产品发布会费用明细.xlsx
├── 4-2-word/
│   └── source/
│       └── 报告写作要求.md
├── 4-3-ppt/
│   └── source/
│       └── 演示文稿制作要求.md
└── 4-4-pdf/
    └── source/
        ├── 01_场地费用确认单_云帆会议中心.pdf
        ├── 02_物料制作结算清单_新彩印务.pdf
        ├── ……
        └── 13_快递费用凭证_四方速运.pdf
```

`产品发布会费用明细.xlsx` 使用虚构数据，不包含真实个人或公司信息。表格故意保留了日期格式不统一、费用分类名称不一致、记录重复和部分字段缺失等问题，供读者练习整理 Excel 文件。

`报告写作要求.md` 给出费用预算、报告对象和写作重点。Word 小节还会读取 Excel 小节生成的整理结果。`演示文稿制作要求.md` 规定 PPT 的汇报对象、页数、内容结构和视觉风格。

`4-4-pdf/source/` 中有 13 份图片型 PDF，共 16 页。它们模拟扫描和手机拍摄的费用资料，并有意保留了旋转、阴影、低对比度、裁边等情况，供读者练习批量阅读、分类和检查文件完整性。所有单位、编号、人员和金额均为虚构内容。

DSH 生成的文件保存在各小节自己的 `output/` 中，不覆盖 `source/` 下的原始文件。
