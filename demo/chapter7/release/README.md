## 剧情梗概

雨后的清晨，老城巷口的小花店开门营业，老板娘把花一盆盆搬到门口，石板路上的积水倒映着灰蓝的天。一个刚经历挫折的年轻人低着头从巷子另一头走来，在花店前停住，看着花发呆。老板娘注意到他，从花桶里挑出一束向日葵递过去，轻声说，花和人一样，晒到太阳，就会重新抬起头。年轻人接过花，低头看了很久，手指碰了碰花瓣，情绪慢慢松动。他捧着花穿过巷子，阳光洒在花上。花店门口，老板娘微笑着目送他走远，镜头慢慢拉远，整条巷子亮起来。

全片几乎无台词，只有老板娘一句轻声的话，靠画面、光线和动作推进情绪。光线从雨后的清冷灰蓝，到云缝漏出的暖黄，再到明亮的午后。

## 制作方法

- 剧本编写：DSH（DeepSeek Harness）根据需求描述生成，完整剧本见 `../script.md`。
- 分镜视频生成：火山方舟 Seedance 2.0 mini（模型 `doubao-seedance-2-0-mini-260615`）文生视频接口，逐镜创建任务、轮询、下载，参数统一为 720p、16:9、6 秒、带同步音频、无水印，脚本见 `../generate_shots.ps1`，源片段在 `../clips/`。
- 合成拼接：ffmpeg concat demuxer 无损拼接 6 个片段（`-c copy`，不重新编码），拼接清单见 `../final/list.txt`。

## 分镜提示词摘要

1. 雨后开门：雨后清晨老城巷口小花店，老板娘搬花出门，灰蓝清冷调，石板路积水倒映天空，檐角滴水，中景缓慢横移。
2. 巷口驻足：年轻人低头走来，背影在花店前驻足看花发呆，老板娘在背景摆花，灰蓝光线，云缝漏下一缕淡光。
3. 递出向日葵：老板娘从花桶挑出向日葵递给他，年轻人愣住，老板娘轻声说一句，暖黄初现，中景侧拍。
4. 接花低头：年轻人接花低头看花，手指碰花瓣，情绪慢慢松动，老板娘转身回去摆花，暖黄增强，中景微推。
5. 捧花过巷：年轻人捧花走过巷子，背影，午后明亮阳光照亮花，脚步轻快，缓慢跟拍。
6. 目送与拉远：花店门口老板娘微笑目送，门前花架，镜头缓慢拉远成远景，温暖收尾。
