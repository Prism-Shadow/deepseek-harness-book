## 剧情梗概

雨夜 23:47，一只湿透的流浪橘猫蜷在便利店门口，隔着玻璃门望向店内关东煮的热气。
值夜班的年轻女店员心生不忍，想开门让它进来——门刚开一条缝，猫就受惊退回雨里。
她放弃直接接触，用一只瓦楞纸箱在屋檐下搭起小屋，从门缝推出去。猫试探后钻入，
安然过了一夜。第二天清晨，阳光照亮小屋，猫叼来一条小鱼干端端正正放在小屋门口，
跑开又回望。店员推门看见谢礼，蹲下捡起鱼干，抬头见猫回望，微笑朝它晃了晃手里的
鱼干——双向信任在这一刻落定。

情绪曲线：心疼 → 犹豫 → 心软 → 温暖 → 惊喜 → 治愈。
光线线索：雨夜的冷蓝 → 清晨的暖阳。

## 制作方法

本片按 **drama-skills 短剧工作流** 在 **dsh（DeepSeek Harness）** 内全流程制作：

1. **制作形态决策**：3D 卡通动画（风格化三维 · 皮克斯式三维卡通渲染），集长目标 40 秒——落成已接受创作者决策并写回 `short-drama.json`（`production_profile`、`target_seconds_per_episode=40`）
2. **剧本**（short-drama-write）：单集卡 + 6 条因果节拍 + 8 场景无台词剧本（字幕承担关键信息），索引校验通过
3. **资产拆解**（short-drama-assets）：橘猫（圆脸/白色胸腹/琥珀色眼/蓬松尾）、店员（马尾/暖色围裙）、便利店内外场景视图、纸箱小屋与小鱼干状态链，`asset_check` 校验通过
4. **分镜**（short-drama-storyboard）：原文落实表 + 8 镜头表 + 8 关键帧 + 关键帧提示词，`storyboard_check` 校验通过（29 个剧本块全覆盖、时长账目一致）
5. **视频提示词**（short-drama-video-prompts）：8 条运动规格（起点/有序动作/表演/摄影机/光线/声音/时间/终点），`motion_timing_check` 校验通过（每镜 5.0s 精确分配）
6. **生产**（short-drama-produce）：8 个 video job 经 prepare 预览 → 创作者确认 → confirm → run，由 **Seedance 2.0 mini（doubao-seedance-2-0-mini-260615）** 文生视频生成，每镜 5s / 720p / 16:9 / 自带音效
7. **合成**（ffmpeg）：8 段按镜头顺序无损拼接（`-c copy`，concat demuxer），ffprobe 验证时长/分辨率/帧率/音视频流

密钥全程只由 adapter 从本机用户目录读取（进程环境内使用），未落盘、未出现在任何产物中。

## 分镜提示词摘要

每镜提示词为完整英文文生视频提示词（含画风约束与角色一致性锚点），存于
`剧集/EP001/storyboard/video-prompts.md`，以下为摘要：

1. **SHOT-001**：湿透橘猫蜷在门垫，0-1s 保持，1-2.5s 抬头望热气，2.5-4s 前倾贴近玻璃，4-5s 保持；锁定猫眼低机位；冷蓝雨夜+店内暖光
2. **SHOT-002**：店员货架前理货，猫叫触发停手，转头望门外猫；锁定中景；暖光店内+门外冷蓝
3. **SHOT-003**：按门把开门缝，猫惊退两步回雨里，松手合门，猫蹭回门垫；锁定机位守因果连续
4. **SHOT-004**：蹲姿托空纸箱，推门缝平推落位，垫干报纸，轻拍退回关门；锁定蹲姿高度机位
5. **SHOT-005**：猫站定嗅闻，绕箱试探探爪，钻入转身蜷起，尾巴盖鼻尖；锁定猫眼低机位
6. **SHOT-006**：深夜猫在箱口探头，缓缓眯眼望店内灯光，尾巴轻摆；锁定；暖光勾轮廓
7. **SHOT-007**：清晨猫叼鱼干，放上门垫正中，抬头看店内，跑开街角回望；锁定；晨光+鸟鸣接上
8. **SHOT-008**：店员推门门铃响，见鱼干怔住，蹲下拾起，抬头见猫微笑晃鱼干；锁定正对门口；晨光铺满
