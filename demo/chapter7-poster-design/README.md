# 第 7 章海报案例配套文件

本目录保存第 7 章《让 dsh 设计活动海报》案例"社区读书会海报"的提示词与设计项目文件。案例使用 Design 插件（deepseek-idesign）配合 dsh，从活动信息和风格要求出发，整理设计简报，生成并调整竖版海报，最后导出成品。

## 目录结构

```text
chapter7-poster-design/
├── README.md                  本说明
├── prompts/                   各环节提示词（与正文对应）
│   ├── 7-2-查看设计简报.md
│   ├── 7-3-确认方案并生成初稿.md
│   └── 7-3-调整配色和文案.md
├── brief.json                 设计简报
├── design-tokens.css          主题令牌（配色、字体、间距等 CSS 变量）
├── index.html                 海报页面（1080×1440 竖版）
└── manifest.json              项目清单（项目类型、入口文件、可编辑变量）
```

## 提示词

`prompts/` 中的提示词按正文小节编号，内容与 `book/chapter7.md` 中给出的提示词一致，可直接复制使用：

- `7-2-查看设计简报.md`：提交活动信息和风格要求，先整理设计简报，不生成设计稿。
- `7-3-确认方案并生成初稿.md`：确认简报内容，指定推荐语、无二维码、1080×1440 竖版，生成初稿。
- `7-3-调整配色和文案.md`：把主色改为墨绿、点缀色改为淡金，并调整报名文案与醒目程度。

## 设计项目文件

Design 插件在运行时会把项目文件写入工作区的 `design/<会话ID>/` 目录。本目录中的四个文件是案例完成后保留的副本，对应第 7.4 节介绍的设计项目文件：

- `manifest.json`：项目清单，声明项目类型、入口文件和可编辑的设计变量。
- `design-tokens.css`：主题令牌，把背景色、文字色、主色、字体和间距定义为 CSS 变量，可集中调整。
- `index.html`：海报正文与版面结构，可在浏览器中打开预览，也能导出为 PNG 或 PDF。
- `brief.json`：设计简报的机器可读版本，记录文案与风格决策。

## 说明

- 海报成品使用无头浏览器渲染 `index.html` 导出，成品的最终配色为墨绿色与淡金色。
- 第 7.3 节还介绍了 Design 视图中的 Edit 精调功能，其修改草稿由插件根据选中元素自动生成，不涉及固定提示词。
