# 02 研究计划：并行任务拆解

> 本文档仅规划任务分工、研究重点、产出文件与依赖关系，暂不开始执行。

## 一、任务总览

依据 `01-研究说明.md` 的比较维度与待确认问题，将调研拆为三个可并行开展的任务：

| 任务 | 名称 | 对应研究说明中的维度 | 产出文件 |
| --- | --- | --- | --- |
| 任务一 | 效果与成本 | 提效收益、成本 | `研究材料/任务一-效果与成本.md` |
| 任务二 | 产品与技术适配 | 产品形态、工具链集成、落地难度 | `研究材料/任务二-产品与技术适配.md` |
| 任务三 | 安全与落地 | 数据安全与合规、推广节奏、退出预案 | `研究材料/任务三-安全与落地.md` |

## 二、任务一：效果与成本

**研究重点**

- 各方案（不引入 / 国际产品 / 国内产品 / 私有化自建）的预期提效收益：编码加速、补全与生成质量、对团队实际工作流的贴合度；
- 各方案的成本构成：订阅或部署费用、培训与推广成本、维护成本；
- 现有公开研究、行业报告与同规模公司案例中的量化指标（如提效比例、采纳率、投入产出比）；
- 建立"引入 vs 不引入"的净增量价值评估框架。

**产出文件**

- `AI代码助手调研/研究材料/任务一-效果与成本.md`

## 三、任务二：产品与技术适配

**研究重点**

- 国际产品（如 GitHub Copilot）与国内产品（如通义灵码、文心快码、CodeGeeX）的功能能力对比；
- 私有化 / 自建方案（基于开源模型或本地部署）的能力与维护要求；
- 各产品对主要技术栈、IDE 与开发工具链（代码托管、CI/CD）的适配情况；
- 国内网络环境下各产品的可用性、访问方式与采购流程差异。

**产出文件**

- `AI代码助手调研/研究材料/任务二-产品与技术适配.md`

## 四、任务三：安全与落地

**研究重点**

- 数据安全与合规：中国境内法规要求、代码出境风险、各产品的数据政策（训练数据使用、日志留存、本地化选项）；
- 供应链与依赖风险：供应商稳定性、锁定风险；
- 落地路径：试点范围、推广节奏、员工培训与接受度、衡量指标与退出预案；
- 对强监管行业背景（如金融、政务、医疗）的适用性评估。

**产出文件**

- `AI代码助手调研/研究材料/任务三-安全与落地.md`

## 五、依赖关系与最终报告

```
01-研究说明.md（范围与待确认问题）
        │
        ├── 任务一 ──→ 研究材料/任务一-效果与成本.md ──┐
        ├── 任务二 ──→ 研究材料/任务二-产品与技术适配.md ─┤──→ 04-决策报告.md
        └── 任务三 ──→ 研究材料/任务三-安全与落地.md ──┘
```

- 三个任务相互独立，可并行开展；
- 任务输出（`研究材料/` 下的三份材料）是最终报告的必要输入，最终报告汇总三份产出，对方案 A–E 做逐维度比较并给出建议；
- 待确认问题的答案（决策人、预算、技术栈、合规要求等）由决策层补充后，作为三个任务与最终报告的公共输入，可对任务范围做相应调整。

## 六、执行前的前置事项

1. 向决策层确认 `01-研究说明.md` 中的待确认问题；
2. 确认三个任务的执行方式（桌面调研、同行访谈等）与时间安排；
3. 得到确认后再开始执行本计划。
