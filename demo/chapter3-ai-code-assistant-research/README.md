# 第 3 章调研案例配套文件

本目录保存第 3 章“让 dsh 完成一次调研”案例的完整结果。案例围绕一家约 200 人、主要在中国开展业务的软件公司是否应引入 AI 代码助手展开。

建议按照下面的顺序阅读：

1. `AI代码助手调研/01-研究说明.md`
2. `AI代码助手调研/02-研究计划.md`
3. `AI代码助手调研/研究材料/` 中的三份并行调研结果
4. `AI代码助手调研/03-核验记录.md`
5. `AI代码助手调研/04-决策报告.md`

三份研究材料是子代理留下的中间产物，其中保留了随后在核验阶段发现的口径冲突和事实错误。阅读时应结合 `03-核验记录.md` 与 `04-决策报告.md`，不要将中间材料单独视为最终结论。

这些文件用于展示第 3 章的真实调研过程。产品信息、价格和政策可能随时间变化，不应直接作为采购或合规决策依据。
