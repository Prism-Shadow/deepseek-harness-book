## 分节要点

### 9.1 分析个人能力

新建 `job-hunt` 工作区，放入材料包。提示词要求 dsh 通读全部文件，产出 `能力档案.md`，规则写死。每条能力注明来自哪份文件哪一段；自我评价和有证据的能力分开；`self-notes.md` 里那些找不到佐证的说法单列存疑，不得混入。验证动作沿用第 2 章习惯，抽一条能力，点开对应的 Read 调用，回材料原文核对。

截图与实测占位。工作区文件列表、能力档案生成过程、证据回指的核对。

### 9.2 市场分析

先定目标岗位（随画像走）。JD 来源见待决策项 2。复用第 5 章方法起多个子 Agent 分头调研，分工大致是岗位核心要求与高频任职资格、行业和城市分布、近期招聘趋势、与本人背景最相关的细分方向。汇总产出 `差距表.md`，四列，岗位要求、现有证据（回指能力档案）、差距、可补救动作。

截图与实测占位。子 Agent 运行状态、差距表成品。

### 9.3 优化简历

从差距表里挑最匹配的一个具体 JD。提示词红线直接写进正文，只许重组和改写材料包里已有的事实，不许新增经历、不许拔高数字。展示 before/after 对照，旧简历某一段和改后同一段并排。本节的验证动作是让 dsh 逐句标注改后简历的证据出处，标不出出处的句子删掉，这一步同时是给读者的方法，防 AI 替你编简历。

截图与实测占位。修改 diff、逐句自查的结果。

### 9.4 模拟面试

复用第 3 章创造模式的路子建一个「面试官」预设，人设是目标岗位的面试官，开场先读工作区里的 JD 和改后简历，追问必须扣着简历内容来。多轮模拟由用户真实作答。结束后让它出复盘报告，哪些回答撑得住、哪些暴露了差距，差距处回指 8.2 的差距表，全章闭环。

倾向用完整 preset 而不是一段临时提示词，更承接第 3 章，也顺便复习预设只对新会话生效那个坑。创造模式实测不顺就降级为在标准模式里用一段固定提示词开新会话，正文按实测结果写。

截图与实测占位。预设创建、面试对话若干轮、复盘报告。
