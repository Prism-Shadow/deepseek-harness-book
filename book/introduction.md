# 内容简介 {.unnumbered #content-intro}

大模型正在从一问一答的聊天工具，变成能够持续执行任务、调用工具、读写文件的智能体（Agent）。要让模型真正替人做事，仅有模型本身还不够，还需要一层负责组织消息、上下文、工具和运行流程的系统，这层系统称为 Agent Harness。DeepSeek Harness（简称 DSH）就是这样一套由插件组装而成的 Agent Harness，它把模型的能力接到人们每天面对的真实任务上。

本书从普通用户真正会遇到的任务出发，分三部分展开。第一部分“玩转 dsh”从安装、接入模型和布置第一个任务讲起，随后通过定制 AI 助手、整理电脑桌面、生成深度研究报告、完成日常办公、处理飞书协作、设计活动海报、构建小游戏、生成个人简历网页和监控市场信号等案例带读者动手实践。第二部分“拆解 dsh”讲清 Harness 的工作原理，以及 dsh 如何通过 cordis 把模型、工具、会话和界面组装成完整系统。第三部分带读者动手扩展 dsh：使用 Skill、MCP 和社区插件，写出自己的第一个插件，并进一步理解如何借助插件 Agent 实现自我进化、把踩过的坑沉淀成每次都会读取的规矩。书中的操作步骤和截图均来自真实运行结果，读者可以对照逐步复现。

本书面向希望让 AI 帮助自己完成实际工作的普通读者，全书以动手操作为主线，配有截图和详细步骤；也适合想了解 Agent Harness 内部机制、为 DSH 开发插件的开发者和技术爱好者阅读。读者既可以按顺序完成全部实战，也可以从任意一个感兴趣的案例直接上手。
