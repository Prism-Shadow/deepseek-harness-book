# 内容简介 {.unnumbered #content-intro}

大模型正在从一问一答的聊天工具，变成能够持续执行任务、调用工具、读写文件的智能体（Agent）。要让模型真正替人做事，仅有模型本身还不够，还需要一层负责组织消息、上下文、工具和运行流程的系统，这层系统称为 Agent Harness。DeepSeek Harness（简称 DSH）就是这样一套由插件组装而成的 Agent Harness，它把模型的能力接到人们每天面对的真实任务上。

本书从普通用户真正会遇到的任务出发，分三部分展开。第一部分从安装 DSH、接入模型、布置第一个任务讲起，随后通过一系列完整案例带读者动手实践，包括定制自己的 AI 助手、让 DSH 整理桌面资料、完成一次多 Agent 分工协作的深度调研、生成整套演示文稿、做一个能玩的小游戏，以及制作并发布个人网页。第二部分讲解 DSH 的工作原理，先拆开任何 Agent Harness 都绕不开的那套循环，从聊天助手到 Agent Harness 的演进、消息与会话、工具调用与结果返回、上下文管理；再深入 DSH 自己的核心 Cordis，讲清楚一切皆插件的模块化设计、能力 Seam 与这套设计背后的取舍；最后单独用一章交代 DSH 的安全边界，沙箱模式、审批策略与权限预设，以及它一以贯之的保守默认。第三部分介绍扩展 DSH 的方法，读者将学会用 Skill 让 DSH 做得更好，用 MCP 接入更多工具，挑选和使用社区插件，动手写出自己的第一个插件；并进一步让 DSH 改写自己正在运行的运行时、写出一个新的 Agent，以及把踩过的坑沉淀成它每次都会读到的规矩。书中的操作步骤和截图均来自真实运行结果，读者可以对照逐步复现。

本书面向希望让 AI 帮助自己完成实际工作的普通读者，全书以动手操作为主线，配有截图和详细步骤；也适合想了解 Agent Harness 内部机制、为 DSH 开发插件的开发者和技术爱好者阅读。读者既可以按顺序完成全部实战，也可以从任意一个感兴趣的案例直接上手。
